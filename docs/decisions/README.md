# Architecture decisions

These records explain choices that are costly or confusing to reverse. They complement code and package types; they are not a second API reference.

## Statuses

`Accepted` decisions describe the current direction. When a choice changes, add a new ADR that references and supersedes the old record. Keep historical ADRs.
